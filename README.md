# Rajkumar S — personal site

Live at **https://rajkumarsethuramalingam.github.io/**

One static page (`index.html`, plain HTML + CSS + a little JavaScript, no build step).
Every push to `main` publishes it with GitHub Actions (`.github/workflows/pages.yml`).

To update: edit `index.html` (or replace `Rajkumar_S_SRE.pdf`), commit and push.
`og.png` is the picture LinkedIn and WhatsApp show when the link is shared.
